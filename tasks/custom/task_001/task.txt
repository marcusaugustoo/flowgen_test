Implemente uma função chamada merge_sorted_arrays(arr1, arr2).

A função deve receber duas listas de inteiros já ordenadas em ordem
crescente e retornar uma nova lista contendo todos os elementos das
duas listas, também em ordem crescente.

Não utilize a função sorted() ou o método .sort(). A implementação
deve realizar a intercalação manualmente.

Exemplos:
- merge_sorted_arrays([1, 3, 5], [2, 4, 6]) deve retornar [1, 2, 3, 4, 5, 6]
- merge_sorted_arrays([], [1, 2]) deve retornar [1, 2]
- merge_sorted_arrays([1], []) deve retornar [1]
- merge_sorted_arrays([], []) deve retornar []
