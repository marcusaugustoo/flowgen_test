Implemente uma função chamada is_anagram(s1, s2).

A função deve receber duas strings e retornar True se elas forem
anagramas uma da outra, e False caso contrário.

A comparação deve ser case-insensitive (ignorar maiúsculas/minúsculas).
Espaços devem ser ignorados na comparação.

Exemplos:
- is_anagram("listen", "silent") deve retornar True
- is_anagram("Hello", "World") deve retornar False
- is_anagram("Astronomer", "Moon starer") deve retornar True
- is_anagram("", "") deve retornar True
