Implemente uma função chamada group_by_frequency(lst).

A função deve receber uma lista de elementos (strings ou inteiros)
e retornar um dicionário onde:
- As chaves são as frequências (número de ocorrências).
- Os valores são listas de elementos que aparecem com aquela frequência,
  ordenados pela ordem em que aparecem pela primeira vez na lista original.

Exemplos:
- group_by_frequency(["a", "b", "a", "c", "b", "a"]) deve retornar
  {3: ["a"], 2: ["b"], 1: ["c"]}
- group_by_frequency([1, 1, 2, 2, 3]) deve retornar
  {2: [1, 2], 1: [3]}
- group_by_frequency([]) deve retornar {}
