Implemente uma função chamada safe_divide(a, b, default=None).

A função deve receber dois números (a e b) e um valor default opcional.

Regras:
- Se b for zero, retornar o valor de default (que por padrão é None).
- Se a ou b forem None, retornar default.
- Se a ou b não forem números (int ou float), levantar TypeError com
  a mensagem "Arguments must be numeric".
- float('inf') e float('-inf') são considerados numéricos válidos.
- float('nan') é considerado numérico válido.
- A divisão deve retornar um float.

Exemplos:
- safe_divide(10, 2) deve retornar 5.0
- safe_divide(10, 0) deve retornar None
- safe_divide(10, 0, default=-1) deve retornar -1
- safe_divide(None, 5) deve retornar None
- safe_divide("10", 5) deve levantar TypeError
