Implemente uma função chamada flatten_nested(data).

A função deve receber uma estrutura arbitrariamente aninhada de listas
e retornar uma lista plana (flat) contendo todos os elementos não-lista,
na ordem em que aparecem.

A função deve lidar com qualquer nível de aninhamento.

Elementos que não são listas (inteiros, strings, None, etc.) devem ser
preservados como estão.

Exemplos:
- flatten_nested([1, [2, 3], [4, [5, 6]]]) deve retornar [1, 2, 3, 4, 5, 6]
- flatten_nested([1, [2, [3, [4, [5]]]]]) deve retornar [1, 2, 3, 4, 5]
- flatten_nested([]) deve retornar []
- flatten_nested([[[], []], []]) deve retornar []
- flatten_nested([1, "hello", [None, [True]]]) deve retornar [1, "hello", None, True]
